개인정보처리방침

1. 처리하는 정보

사용자가 직접 입력한 구독 내역과 가성비 계산을 위한 앱별 사용 시간 정보는 이 기기 내부에서만 사용되며 외부로 저장·전송되지 않습니다.

2. 수집·전송·제3자 제공

구독정리는 별도 서버나 회원가입을 운영하지 않으며, 어떠한 정보도 개발자나 제3자에게 전송·제공하지 않습니다.

3. 권한 안내

사용 정보 접근(PACKAGE_USAGE_STATS) 권한은 가성비 점수 계산용 선택 사항입니다. 알림 권한은 결제일 하루 전 알림 발송에만 사용됩니다.

4. 정보의 삭제

앱을 삭제하거나 앱 데이터를 지우면 기기에 저장된 모든 정보가 즉시 삭제됩니다.
